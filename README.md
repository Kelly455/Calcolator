# Calculator

A functional calculator built with HTML, CSS, and vanilla JavaScript.
The calculator handles basic arithmetic operations, percentage calculations,
and chained calculations while providing immediate feedback through the display.
The interface uses a grid-based layout, including a 0 button that spans two
columns for a more natural calculator design.

## Features
- Perform basic arithmetic calculations
- Calculate percentages immediately
- Support percentages within chained calculations
- Display calculation results and user input in real time
- Grid-based layout with the 0 button spanning two columns for a natural calculator feel

## Built With
- HTML5
- CSS3
- JavaScript (vanilla, no frameworks or libraries)

## How to Run
1. Clone or download this repository
2. Open index.html in a web browser
3. No installation, dependencies, or build process is required

# What I Learned

This project gave me practical experience building calculator logic with
plain JavaScript. I learned how to organize operator behavior using three
branches, handle percentage calculations both immediately and as part of
chained operations, and connect the JavaScript logic to the calculator
display. I also worked through a display-feedback bug, traced where the
problem was occurring, and fixed it so the interface correctly reflects the
user's actions and calculation state.
